# 最终验收截图/证据清单

本清单用于验收现场截图、录屏和日志归档。正式平台口径仍以 [平台联调验收口径.md](./平台联调验收口径.md) 为准。

## 1. 总览页联调状态看板

- 页面入口：`http://127.0.0.1:5173` 登录后进入“总览首页/联调状态看板”
- 截图重点：联调状态看板整块区域
- 应看到的关键字段：
  - 最近设备：`A110000_0001`
  - 最近接收状态：`接收成功`
  - 最近接收结果：`TCP 已接收并入库`
  - ACK 状态：`ACK 正常（已收到 CN=9014）`
  - ACK 包摘要：`平台已返回 CN=9014 ACK`
- 对应 API/JSON 证据：
  - `GET http://127.0.0.1:8000/api/v1/dashboard/summary`
  - `integrationStatus.lastDevice = A110000_0001`
  - `integrationStatus.lastStatus = accepted`
  - `integrationStatus.lastReceiveResult = TCP accepted and stored`
  - `integrationStatus.lastAckStatus = valid_9014_ack`
  - `integrationStatus.lastAckSummary = CN=9014 ACK returned`
- 说明：页面展示中文，API 保留机器值，二者不是冲突。

## 2. 协议接收日志

- 页面入口：`http://127.0.0.1:5173` 左侧导航进入“协议接收日志”
- 截图重点：最新一条 TCP 报文记录及展开后的原始报文/平台应答
- 应看到的关键字段：
  - 来源：`TCP 接收`
  - `MN = A110000_0001`
  - `CN = 2011` 或 `CN = 2061`
  - 状态：`接收成功`
  - `metricCount` 与当前报文指标数一致，QA 固定守门包为 `5`，PC 真实联调包可能为 `3`
  - 平台应答包含 `CN=9014`
- 对应 API/JSON 证据：
  - `GET http://127.0.0.1:8000/api/v1/protocol/logs`
  - 最新记录应包含 `source=tcp`、`mn=A110000_0001`、`status=accepted`
  - `metricCount` 应与当前报文指标数一致；守门日志固定验证 `protocolLog.metricCount = 5`
  - 最新记录的 `ackPacket` 应包含 `CN=9014`
  - 守门日志 `logs\acceptance\tcp-acceptance-*.json` 中 `protocolLog.status = accepted`

## 3. 实时监测

- 页面入口：`http://127.0.0.1:5173` 左侧导航进入“实时监测”
- 截图重点：最新监测指标列表
- 应看到的关键字段：
  - `w01010`
  - `w01014`
  - `w01001`
  - `w01017`
  - `w01019`
  - 状态标记：`正常`
  - 最新值与固定验收报文一致或可对应
- 对应 API/JSON 证据：
  - `GET http://127.0.0.1:8000/api/v1/telemetry/latest`
  - 守门日志 `logs\acceptance\tcp-acceptance-*.json` 中 `telemetryLatest.sensorCode = w01010`
  - 固定实时包期望 `w01010 = 28.6`
  - API 原始质量标记可为 `N` 或 `good`，页面统一展示为 `正常`

## 4. ACK 包

- 页面入口：协议接收日志中的 `ackPacket` 字段，或 PC/QA 控制台 socket 收包输出
- 截图重点：完整 ACK 原文或守门 JSON 中的 `tcpAckRaw`
- 应看到的关键字段：
  - `CN=9014`
  - `ST=91`
  - `Flag=8`
  - `MN=A110000_0001`
- 对应 API/JSON 证据：
  - 守门日志 `logs\acceptance\tcp-acceptance-*.json`
  - `ackPolicy = required`
  - `ackValidation.valid = true`
  - `ackValidation.cn = 9014`
  - `tcpAckRaw` 包含 `CN=9014`

## 现场归档建议

- 截图文件建议命名：`01-dashboard-ack.png`、`02-protocol-log.png`、`03-telemetry-latest.png`、`04-ack-packet.png`
- JSON 证据建议归档最新的 `logs\acceptance\tcp-acceptance-*.json`
- 如果 PC 侧截图中没有 ACK 原文，则必须保留平台 `tcpAckRaw` JSON 证据作为补充
