# PC 侧最终验收步骤

1. 启动平台 TCP 接收服务，确认监听 `127.0.0.1:9100`，并对合法 HJ212 报文返回 `CN=9014` ACK。
2. 打开 PC 软件，停留在首页，确认首页显示目标地址 `127.0.0.1:9100`，ACK 策略为“必须”，ACK 等待默认值为 `3.0` 秒。
3. 点击“测试平台”，确认 TCP 连接可达。
4. 进入“参数设置 -> 基本参数”，确认实时保存间隔默认值为 `30` 秒；如需调整，只能在下拉框选择 `30 秒` 或 `60 秒`。
5. 选中一台已绑定因子的设备，点击“采集选中设备”，再点击“上传待处理数据”。
6. 查看首页状态区，成功判据为：连接状态“已连接”、最后发送结果“已发送并收到 ACK”、ACK 状态“已收到 ACK”。
7. 查看首页“离线缓存/补传”提示，确认待上传、失败待重试、重复跳过数量清晰可见；补传或重试不应被误认为重复上传。
8. 点击“查看最后一帧”，核对并复制原始报文；重点检查 `MN=A110000_0001`、`CN=2011`、`DataTime` 和 `w01010/w01014/w01001/w01017/w01019` 等因子编码。
9. 进入“数据分析”，查看水温、pH、溶解氧、电导率、浊度等趋势，以及本地质量提示：超标、疑似离群、疑似恒值；页面口径应显示“本项目地表水技术要求目录 + 可配置阈值”，建议需结合现场复核。
10. 到平台页面确认同一帧已解析入库，平台原始报文与 PC “最后一帧”一致。

失败定位提示：

- “未连接到 127.0.0.1:9100”：平台服务未启动、端口未监听或地址不一致。
- “连接成功但未收到 ACK”：PC 已发出报文，但平台未在 ACK 等待窗口内写回。
- “收到 ACK 但不是 CN=9014”：平台有回包，但命令码不符合验收口径。
- “平台返回 ERROR”：平台接收到了报文，但解析或入库阶段返回错误。
- “重复报文已跳过”：PC 已识别同一轮同指纹报文，未再次发送。

本地质量提示边界：

- PC 侧只做本地提示，不做最终告警归档。
- 口径为“本项目地表水技术要求目录 + 可配置阈值”；GB 3838 可作为默认阈值参考背景，GB 11607 不作为 PC 本地主判断依据。
- 阈值来自 `analysis_thresholds_json` / `analysis_quality_rules_json` 配置，默认只做参考建议，需复核现场。
- 短信通知和最终告警以平台解析、平台规则和平台通知链路为准。

失败时请收集：

- 首页状态区的目标地址、连接状态、最后发送结果和 ACK 状态。
- “查看最后一帧”中的原始报文。
- 平台 TCP 服务进程、监听端口、原始接收报文和 ACK 写回日志。
- 当前 PC 配置项：`PLATFORM_HOST`、`PLATFORM_PORT`、`PLATFORM_ACK_TIMEOUT_SECONDS`。
- 首页“离线缓存/补传”状态和“数据分析”质量提示截图。
